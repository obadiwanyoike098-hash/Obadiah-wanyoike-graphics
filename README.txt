OBADIAH WANYOIKE GRAPHICS DESIGN — WEBSITE STARTER

CONTENTS
- index.html: website structure and content
- style.css: layout, responsive styling, black-and-gold theme
- script.js: mobile menu, portfolio filters, image lightbox, enquiry handling
- assets/: the six portfolio images supplied in the chat

IMPORTANT SETTINGS
1. Open script.js in a text editor.
2. Find: const WHATSAPP_NUMBER = "";
3. Later, replace the empty quotes with your WhatsApp number in international digits-only format.
   Kenya example format: 2547XXXXXXXX (do not include +, spaces, or hyphens).
4. Save the file.

PRICES AND CONTACT
- Prices are placeholders. Edit them in index.html before publishing.
- The email is intentionally a placeholder.
- The enquiry form does not store submissions. When a WhatsApp number is configured, it opens WhatsApp with the visitor's message.
- Some portfolio images contain contact details and campaign content. Check that you have permission to publish them and that visible details are correct before making the site public.

PREVIEW ON ANDROID
1. Extract the ZIP into a folder using a file manager.
2. Open index.html in a browser if your file manager allows it.
3. If local preview does not load CSS/JavaScript correctly, use an Android-friendly HTML editor with preview or upload the folder to a static hosting service.

FREE HOSTING
This is a static site and can be hosted on a compatible free static hosting service. You will need to create and manage the hosting account yourself; this package does not publish the website automatically. A custom domain is optional and may cost money.

BEFORE PUBLISHING
- Replace all price placeholders.
- Add your actual WhatsApp number and email if desired.
- Review every portfolio image and its permissions.
- Test all links and the contact flow on your phone.
- Do not put passwords or secret API keys into these public website files.
